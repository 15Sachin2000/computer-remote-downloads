# Computer Remote — public preview downloads

This repository distributes preview installers and SHA-256 checksums. The application source repository remains private.

Download builds from the Releases page. Your phone and computer must be on the same Wi-Fi, with the desktop companion running. Pair using the QR code shown by that companion.

Mac builds are locally signed preview builds and are not Apple notarized. The Windows portable app is not Authenticode-signed. Android is a debug-signed APK. Platform launch/HTTPS checks do not replace testing on your own devices.

A native iOS app is not available; use the companion's web QR code in your phone browser.
